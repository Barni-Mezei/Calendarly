# Naming conventions

*Identifier: **Any name.** Can be a variable, a function or an enum name.*

Identifier names should be in camle case: `longVariableName`
Global identifiers should be in upper snake case: `GLOBAL_VAR`

Class names should be in upper camel case: `LongClassName`

# Strings

Strings are should be always in double quotes (`"`) instead of single ones.

# Functions

Boolean function arguments should always start with `is_` ex.: "is_required"

# Code formatting

Code indentation should be set to **4 spaces** and line endings should be **LF** instead of **CRLF**
Keep all code consistent with other code snippets.
Avoid unnecessary empty lines.

**Functions** should be separated by **2 empty lines**
**Logical blocks** should be separarted with **3 empty lines**

Always keep at least one empty line at thbe end of a file.
