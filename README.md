***Calendarly*** is a calendar web app designed for planning and organising events for small groups. This app is an ideal choice for planning family gatherings, birthday parties or any event where the number of people involved would make messaging groups complicated to use.

Visit [calendarly.io](https://calendarly.io/) to try it out!

# How to use

- First, register an user, or create a link based event.
- Then invite your friends to the event, or send them the link.
- After joining, select the date ranges you would be available for this event.
- When everyone is done selecting ranges, the best possible date will be shown, from the intersection of all submitted ranges.
